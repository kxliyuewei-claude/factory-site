BatchRename Pocket Privacy Policy

Effective date: 2026-06-08

BatchRename Pocket is a local-first file renaming utility. It works without accounts, analytics, advertising, tracking, or cloud upload.

Data Collection

BatchRename Pocket does not collect personal data. The app does not collect, transmit, sell, share, or analyze files selected by the user, file contents, file names, usage analytics, contact information, location data, device identifiers, or advertising identifiers.

File Access

BatchRename Pocket only accesses files that the user explicitly selects through the system file picker. The app uses selected files to generate renamed copies. Original files are not modified, deleted, or uploaded.

Local Storage

BatchRename Pocket may save local app settings such as the most recent naming rule. This data remains on the user's device and is not transmitted to the developer or any third party.

Network Use

BatchRename Pocket does not require network access for its core features.

Third-Party SDKs

BatchRename Pocket does not use third-party SDKs.

Tracking

BatchRename Pocket does not track users across apps or websites.

App Privacy Summary

  • Data collected: No data collected
  • Tracking: No
  • Third-party advertising: No
  • Analytics: No
  • Data linked to user: No
  • Data used to track user: No
